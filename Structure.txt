🧠 Why This Is Important

Without caching:
Client
  │
  ▼
Application
  │
  ▼
Database
  │
  ▼
Every request hits DB ❌

With Redis:
Client
  │
  ▼
Application
  │
  ▼
Redis Cache
  │
 ┌┴──────────────┐
 │ Cache Hit     │
 │      ↓        │
 │ Return Data   │
 └───────────────┘

Cache Miss
    │
    ▼
Database

For multiple Redis nodes, we can distribute keys using consistent hashing:

              Hash Ring

          Redis Node 1
               ●
          /           \
         /             \
 Redis Node 3         Redis Node 2

Benefits:
✅ Faster responses
✅ Reduced database load
✅ Distributed cache
✅ Horizontal scalability
✅ Minimal key movement when nodes change
